### 2.2 从表格结构能确证的三件事

1. **这是一张"两段式"链**：**开采段（岩石/矿石/煤炭/原油/木头/粮食/家畜/蔬菜/棉花 → 基础原料）** → **加工段（基础原料互相组合 → 中间品 → 终产品）** → **终产品分两路消化：工业/办公升级 与 商业消费**。
2. **"用途（公司）"一列明确区分了三类去向**（这是本表相对官方 Wiki 最有价值的补充）：
   - **供应消费**（第 11、13、15、22、23 行）→ 走**商业区**；
   - **生产/升级**（第 1、2、3、5、6、7、8、16 行）→ 走**工业区内部的建筑与公司升级**；
   - **供应服务需求**（第 9、10、20 行药品 / 电子产品 / 电信、第 17、18 行纸张 / 家具"供应消费/办公区"）→ 走**服务建筑与办公区**。
3. **存在明确的"多用途依赖"**：**电子产品**同时是 **软件（→金融/媒体/电信）** 和 **电信** 的输入，而**电信又要回头供应工业区与办公区**——形成"工业 ↔ 办公"的**双向依赖环**（第 10、19、20 行）。这是本表最重要的一条结构性结论。

#### → 可用于 CSL2 建议的规则
- **建"闭环"而不是"单向链"**：**电子产品的产能必须同时喂饱"软件"和"电信"两条下游**，而电信又反过来服务工业与办公。游戏化建议：**办公区规模要与本地电子产品的产能匹配**——办公区铺得太大而本地没有电子产业，会导致大量办公公司拿不到资源、效率下滑（对应 `10-game-mechanics.md` §7.7「制造业依赖办公区产出的 Software」，官方口径）。
- **不要只做"开采→出口"**：表中第 12–15、22–23 行说明**农业与纺织线全部指向"消费"**。游戏化建议：**农业专业区必须配商业区消化**（饮料/方便食品/加工食品/纺织品都是"供应消费"），否则只能靠货运外运。
- `[游戏机制]`（本表拓扑 + 官方 Wiki 交叉）：本表**未标注版本号细节**，1.2 之后是否有改动**本表无法证明**。

### 2.3 表格隐含的用地含义（按本轮目标解读）

| 链条 | 涉及的建筑/分区 | 用地含义（据本表拓扑 + `10-game-mechanics.md`） |
|---|---|---|
| 矿石 → 金属 → 钢铁 → 机械 | **采矿专业区 + 工业区** | 上游要占用**地图上的资源点**（不可移动），下游工业区要靠近货运 |
| 岩石 → 矿物质/混凝土 | 采矿专业区 + 工业区 | **混凝土直接服务"房屋升级"**——是**建筑业的地基** |
| 原油 → 石化产品 → 塑料 → 电子产品 | 采油 + 工业区 | **链条最长（4 级）**，中间品多，**占地与货车流量最大** |
| 木头 → 木材 → 家具/纸张 | 林业 + 工业区 | 家具/纸张"供应消费/办公区"，**两头都要有** |
| 粮食/家畜/蔬菜/棉花 → 食品与纺织 | 农业专业区 + 工业区 | 全部指向**商业消费** |
| 电子产品 → 软件 → 金融/媒体/电信 | **办公区** | **办公区不是"独立产业"，它是电子产品与软件的下游** |

#### → 可用于 CSL2 建议的规则
- **"链条越长，途中货车越多"**：原油线（原油→石化→塑料→电子）是本表最长的一条，**每一级都要一次运输**。
  游戏化建议：**把这四级放在同一条货运走廊上**（沿高速/货运铁路/港口成串布置），**不要在城市两头各放一半**。这直接减少穿城货车 = 减少拥堵与噪声（幸福度）。
- **"采矿/采油/林业被资源点锁死"**：第 1、3、4、6、7、16 行的输入端是**地图资源**，位置不可选。
  游戏化建议：**先看资源点分布再定工业区位置**，把加工段紧贴资源点（而不是紧贴市中心）——这是**用地效率最高**的布局。
- **办公区应布置在电子产品产能附近，而不是随便找块地**：第 19 行（电子产品 → 软件）决定了办公区的上游。
  游戏化建议：**办公区与工业区之间要有直接、短的货运连接**（高速或货运站），否则软件/电信链路会断。

### 3.2 交通效率（货运流量）相关的可执行判据

| 判据 | 依据（本表） | 换成 CSL2 的操作 |
|---|---|---|
| **链条级数 = 运输次数** | 每行"输入→产出"就是一次运输（1–23 行全部如此） | **把同一链条的上下级放在同一条货运走廊上**；链条越长越要靠高速/货运铁路/港口，而不是城市道路 |
| **"多对一"的输入行最堵** | 第 15 行（棉花+家畜+石化产品→纺织品）、第 8 行（化学品+石化产品→塑料）是**三输入/双输入** | 这类工厂周围要预留**更大的接货区与货车停车**，并避免只有一条支路接入 |
| **"一对多"的产出行最分散** | 第 10 行（电子产品 → 软件、电信）、第 16 行（木材 → 家具、纸张） | 这类工厂要靠近**货运枢纽**，否则同一批货要跑两个方向 |
| **工业 ↔ 办公是双向环** | 第 20 行（电子产品+软件→电信→供应工业区和办公区需求） | **工业区与办公区之间必须有一条短、直、高容量的连接**；两者相距过远会同时拖累两侧效率 |
| **终产品必须靠近消费者** | 第 11、13、15、22、23 行都是"供应消费" | 食品/纺织/载具工厂**应靠近商业区**（或靠货运站中转），不要放在地图另一头 |

### 3.3 幸福度相关的可执行判据

| 判据 | 依据 | 换成 CSL2 的操作 |
|---|---|---|
| **药品是唯一的"服务需求"输入** | 第 9 行（化学品 → 药品 → **供应医疗服务需求**） | **药品产能直接关系到医疗服务**——缺药会打到幸福度。**化学品产能要优先保药品** |
| **混凝土决定房屋升级** | 第 4 行（岩石 → 混凝土 → **房屋升级**） | 房屋升级停滞 = 地价上不去 = 住宅税收上不去。**混凝土供给是"税收增长"的前置条件** |
| **"增加娱乐值"的饮料线** | 第 12 行（粮食+蔬菜 → 饮料 → **增加娱乐值**）、第 23 行（饮料 → 娱乐 → 供应消费） | **饮料→娱乐是本表唯一直接写"增加娱乐值"的链路**，属于幸福度直接抓手 |
